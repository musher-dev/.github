# Support

## Using Musher

- **Documentation:** [docs.musher.dev](https://docs.musher.dev) covers deploying
  and running agent stacks on Musher.
- **Questions:** ask the community and team on
  [Discord](https://discord.gg/SaVMzMgX2c).
- **Account and billing:** email [support@musher.dev](mailto:support@musher.dev)
  or [billing@musher.dev](mailto:billing@musher.dev).

## Bugs and feature requests

Open an issue in the repository it concerns and pick a form: Bug, Feature
Request or Task. Issues land on the
[Product Delivery board](https://github.com/orgs/musher-dev/projects/1) for
triage.

## Security

Never report a vulnerability in a public issue. Follow the
[security policy](SECURITY.md) instead.
